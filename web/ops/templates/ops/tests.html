Test runs

A test run replays injects on a compressed clock through the real scheduler. In SIMEX Mail, messages land in the Test team inbox (with a banner naming the real team); by email they go to the test address pattern below. Choose the channel for the run, whatever Settings → Delivery channel says for the live exercise. It uses the injects as they are when each one fires, so edits show up. Live sending does not need to be armed; Pause all sending also pauses test runs.
